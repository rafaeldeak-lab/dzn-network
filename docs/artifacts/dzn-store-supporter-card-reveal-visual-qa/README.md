# DZN Store Supporter Card Reveal Visual QA Artifact

This folder contains local seeded preview evidence for the private `/account/purchases` Supporter Card reveal polish slice.

It is not a retained export feature. It is not generated from production. It creates no files at runtime and does not store player share history, Supporter Card screenshots, card art, payment details, or private customer data.

The JSON artifact documents the expected local/test visual states:

- Read model disabled.
- No Store purchases.
- Private Supporter Card status with masked serial.
- Private Supporter Card revealed for the current account.
- Private reveal unavailable.
- Cross-account denied.

All references are fake local/test values. The artifact contains no raw DZN user ids, Discord ids, Stripe ids, payment methods, billing addresses, internal order ids, internal entitlement ids, internal Supporter Card ids, webhook raw bodies, provider payloads, operator notes, real customer data, or production data.
